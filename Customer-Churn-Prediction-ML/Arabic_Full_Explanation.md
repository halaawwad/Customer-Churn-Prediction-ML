# شرح كامل لمشروع Customer Churn Prediction

## الفكرة العامة
المشروع يتعامل مع مشكلة مهمة في شركات الاتصالات: كيف نتوقع الزبائن الذين من المحتمل أن يتركوا الشركة. هذا يسمى Customer Churn. الهدف هو بناء نظام Machine Learning يأخذ بيانات الزبون وخدماته وطريقة الدفع ومدة اشتراكه، ثم يتوقع هل سيترك الشركة أم لا.

## لماذا هذا المشروع مهم؟
الشركات تفضل الحفاظ على الزبائن الحاليين لأن تكلفة الاحتفاظ بالزبون عادة أقل من تكلفة جلب زبون جديد. إذا عرفنا مبكرا أن زبونا معرض للمغادرة، يمكن للشركة أن تقدم له عرضا أو دعما أفضل.

## الداتا
الداتا المطلوبة هي Telco Customer Churn Dataset. فيها معلومات ديموغرافية مثل الجنس والعمر، معلومات خدمات مثل الإنترنت والدعم الفني، ومعلومات الحساب مثل نوع العقد وطريقة الدفع والرسوم الشهرية. العمود الهدف هو Churn وقيمته Yes أو No.

## خطوات الحل
1. Data Understanding: فهم الأعمدة، أنواع البيانات، توزيع Churn، واكتشاف العلاقات المهمة.
2. Data Cleaning: تحويل TotalCharges إلى رقم، معالجة القيم الناقصة، حذف customerID، وتحويل الأعمدة النصية لأرقام.
3. Sampling: تقسيم الداتا إلى 70% تدريب و30% اختبار مع الحفاظ على نفس توزيع Churn باستخدام stratify.
4. Feature Analysis: تحليل الأعمدة المهمة باستخدام correlation و Decision Tree feature importance.
5. Classification: تدريب Decision Tree و SVM.
6. Clustering: استخدام K-Means لاكتشاف مجموعات زبائن مخفية.
7. Evaluation: مقارنة الموديلات باستخدام accuracy, precision, recall, F1-score, confusion matrix.

## كيف تشغل المشروع
1. نزل الداتا من Kaggle.
2. ضع ملف CSV داخل مجلد data.
3. ثبّت المتطلبات:
   pip install -r requirements.txt
4. شغّل:
   python src/churn_prediction.py
5. النتائج والرسومات ستظهر داخل results.

## ملاحظات مهمة للتقرير
ركز في المناقشة على معنى النتائج وليس فقط الأرقام. مثلا إذا كان recall أعلى في SVM فهذا يعني أن SVM أفضل في اكتشاف الزبائن الذين سيتركون الشركة. وإذا كان Decision Tree أقل دقة لكنه أسهل في التفسير، فهذا يعتبر trade-off مهم.
