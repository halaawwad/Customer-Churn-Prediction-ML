# Interactive Dashboard

Open `dashboard/index.html` in a browser after running the Python pipeline.

The dashboard is organized as an interactive visual lab:

- Use the top buttons to jump to Project Overview, PCA Impact, Model Results, or Visuals.
- Use category buttons to filter charts by project stage.
- Click `View` / `Open Chart` to reveal each chart with its explanation.
- The page no longer displays the run timestamp; it focuses only on project results.

Data is loaded from `dashboard/latest_results.js`, which is generated by `src/churn_prediction.py`.
